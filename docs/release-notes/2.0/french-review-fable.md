# MegaPDF 2.0 — French review (Fable), findings only

**Verdict: ship-ready French with a short fix list.** Nothing in the app's fr-CA or fr-FR strings is wrong enough to block 2.0; the store copy has a handful of things that should be fixed before it is pasted, one of which is a factual contradiction rather than French. **52 findings: 10 error, 19 should, 23 taste.** *Update 2026-09-18, 08:15 EDT:* the ten errors are fixed on `main` (#245: `5043f6d`, `01ba248`, `3965654`, `08c3865`); each is marked in its row. The *should* and *taste* items are held for the pass that merges this review with the human reviewer's. All 37 flagged rows of the pack get a verdict below; 32 stand as written, 5 want a wording change.

This is an independent parallel read, not a replacement for the human francophone review; it changes no strings. Fixes are to be applied later from both reviews together. Read on 2026-09-18 against `origin/main` at `c64a440`.

Severity: **error** = wrong (meaning, grammar, a stated rule, a field limit, a factual claim); **should** = correct but inconsistent, calqued, a truncation risk, or not the platform's own word; **taste** = a native speaker might prefer it, nothing breaks.

`⍽` is a non-breaking space (U+00A0) made visible, as in the pack.

**The pack's four applied corrections (§2):** all four confirmed. **The pack's five questions (§3):**

1. *Masquer / Réduire doing double duty.* Context carries it, as it does for Annuler. Leave the toolbar verbs alone; Apple's menu words cannot move and a toolbar « Couvrir » would then differ from the hint text that says « masquer ».
2. *Apostrophes.* Straight `'` is a defensible house style, and it is now consistent on Mac, Android and iOS — Windows has exactly one `’` (F-C5). If one platform is to switch, it is the Apple ones, where every system string uses `’`. Taste, not a defect.
3. *Caviarder.* Keep — row 24.
4. *Afficher dans Fichiers.* Keep — row 29.
5. *Length.* Two strings are more than twice their English and sit in tight places: « Application de la modification… » on the page spinner (F-E4) and « Fermer les options supplémentaires » as a Narrator name (spoken, so harmless). Everything else is within ordinary French expansion.
