# Real-document fixtures

Binary PDFs that the synthetic generator (`tools/gen_test_fixtures.py`) cannot
stand in for. Each one is public and redistributable; say where it came from
when adding another.

| file | source | why it is here |
|---|---|---|
| `microbit-v2-schematic.pdf` | micro:bit V2.2.1 (nRF52820) schematic as published by the Micro:bit Educational Foundation with the open-hardware design files for the board | #98: the corpus stress run once returned 13 matches for "the" on this file on macOS, and 12 on every other run on both platforms. `SearchParityTests` asserts 4 / 6 / 2 per page so every CI run is another sample. The same bytes sit in `ios/MegaPDFTests/` and `android/engine/src/androidTest/assets/` for the mobile engine tests. |
| `userunit.pdf` | generated by `tools/gen_test_fixtures.py` (committed copy) | #150: `/UserUnit 2` with an offset CropBox, so `UserUnitTests` can assert sizes and placements in points; the same bytes sit in `android/engine/src/androidTest/assets/`. Regenerate both copies when the generator changes. |
| `subset-font.pdf`, `cid-font.pdf` | generated by `tools/gen_subset_font_fixture.py` / `tools/gen_cid_font_fixture.py` (committed copies) | #130/#126: an embedded TrueType (subset and CID) heading, so the tier-2 substitution tests exercise a real font program without fontTools on the CI runners. |
| `structure/*.pdf` | generated by `tools/gen_structure_fixtures.py` (committed copies) | #142, #353: `columns.pdf`, `furniture.pdf`, `lists.pdf`, `headings.pdf`, `xobject-text.pdf`, `scan.pdf`, `mixed.pdf` — contract 9's fixtures (design §7), each embedding DejaVu Sans/Sans Bold so their golden `core/tests/expected/structure/*.blocks` files can be exact on every CI OS, unlike `text_runs.txt`'s non-embedded base-14 fixtures (see that file's own comment in `core_tests.cpp`). fontTools is not on the CI runners, so — like the two rows above — these are generated once and committed rather than built by `tools/gen_test_fixtures.py`'s CI step. |

These are copied to the test output by the project file (`Fixtures\**`).
